# Annette's Big Day

A pixel-art birthday RPG. Open `index.html` in a browser to play.

- **Play:** double-click `index.html`, or run `python3 -m http.server 8000` and visit http://localhost:8000
- **Personalise:** edit the `CONFIG` block at the top of the script in `index.html`
- **Continue building:** open this folder in a terminal, run `claude`, and paste the prompt from `PROMPT.md`
- **Assets:** `assets/sprites` (1x PNGs), `assets/sprites-8x` (8x PNGs), `assets/sprites.json` (source), `assets/sprite-sheet.png`, `assets/screenshots`
